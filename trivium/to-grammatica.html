Bridge

Go and practice grammar

❧

The preceding account said what this art is for; the set of exercises is where we practice it. Ars Grammatica begins with the opening study, What Grammar Is, the preliminary that the set of exercises itself marks “start here.” That preliminary is not scored. That deck is an orientation: grammar as an art that frees us to say what we mean, the well-formed as distinct from the true, and the progression from voice to the complete arrangement. The studies then continue in the order of the set of exercises; the next study in that order is What Grammar Is For. We do not skip the preliminary on the ground that it is not scored.

We return to this course when we can say, in our own words, what grammar asks that logic and rhetoric do not. A good test is Walshe’s pair: if we can tell why “man is stone” is a grammatical success and a logical failure, and why “man are animal” is the reverse, we have the distinction this lesson needed. The set of exercises then takes up the parts and magnitudes of speech, and this course will not duplicate those drills.

The study deck to begin with is What Grammar Is, which the set of exercises marks “start here.” The address is grammatica.studiuminstitute.org.

Open Ars Grammatica practice

The default recommendation is to finish a first pass of grammar before logic. Logic comes first only if we cannot yet tell a statement from a question or a command. Rhetoric comes first only if we are already caught in empty debate and need to see what persuasion is for, and even then we return to grammar. When the terms become unclear later, we return to this account and to the set of exercises. The cycle this course intends is an ordinary one: doctrine, then practice, then doctrine again with better questions.

When we come back

We decide when a first pass is finished; nothing here is a test. But there is a way to tell, and it is not the number of decks we have finished. The test is to say the following aloud, in our own words, without opening anything:

  • What grammar asks that logic and rhetoric do not.
  • Why man is stone is a grammatical success and a logical failure, and man are animal the reverse.
  • Why a well-formed sentence is not yet a true one, and where truth does arrive.

If those come, we have what this lesson was for. If the second will not come, that is the one to return to, since it is the principle of the whole trivium.

When we come back

Then the first art has had its first pass, and we are in the part of this course that most students never reach, namely, the return. Grammar is not finished (an art is not finished), but it has been begun in the only way an art can be begun, by doing it.

The next art is Logic. The second art assumes exactly what we have just practiced: that there are terms that mean, and sayings that are composed. Logic will ask what follows logically from them.

We return to grammar, and to Ars Grammatica, whenever the terms become unclear in the middle of something else, that is, whenever we cannot tell what is being said of what. That is not a step backward; it is the cycle working as it should.
