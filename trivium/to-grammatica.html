Bridge

Go and practice grammar

❧

The preceding account said what this art is for; the set of exercises is where it is practiced. Ars Grammatica begins with the opening study, What Grammar Is, the preliminary that the set of exercises itself marks “start here.” That preliminary is not scored. That deck is an orientation: grammar as an art that frees the student to say what is meant, the well-formed as distinct from the true, and the progression from voice to the complete saying. The studies then continue in the order of the set of exercises; the next study in that order is What Grammar Is For. The preliminary is not to be skipped on the ground that it is not scored.

The return to this course comes when one can say, in one's own words, what grammar asks that logic and rhetoric do not. A good test is Walshe’s pair: if one can tell why “man is stone” is a grammatical success and a logical failure, and why “man are animal” is the reverse, one has the distinction this lesson needed. The set of exercises then takes up the parts and magnitudes of speech, and this course will not duplicate those drills.

The study deck to begin with is What Grammar Is, which the set of exercises marks “start here.” The address is grammatica.studiuminstitute.org.

Open Ars Grammatica practice

The default recommendation is to finish a first pass of grammar before logic. Logic comes first only if a statement cannot yet be distinguished from a question or a command. Rhetoric comes first only if one is already caught in empty debate and needs to see what persuasion is for, and even then the return is to grammar. When the terms become unclear later, the return is to this account and to the set of exercises. The cycle this course intends is an ordinary one: doctrine, then practice, then doctrine again with better questions.

On returning

The student decides when a first pass is finished; nothing here is a test. But there is a way to tell, and it is not the number of decks that have been finished. The test is to say the following aloud, in one's own words, without opening anything:

  • What grammar asks that logic and rhetoric do not.
  • Why man is stone is a grammatical success and a logical failure, and man are animal the reverse.
  • Why a well-formed sentence is not yet a true one, and where truth does arrive.

If those come, the lesson has done what it was for. If the second will not come, that is the one to return to, since it is the principle of the whole trivium.

On the return

Then the first art has had its first pass, and the return is the part of this course that most students never reach. Grammar is not finished (an art is not finished), but it has been begun in the only way an art can be begun, by doing it.

The next art is Logic. The second art assumes exactly what has just been practiced: that there are terms that mean, and sayings that are composed. Logic will ask what follows logically from them.

The return to grammar, and to Ars Grammatica, is for whenever the terms become unclear in the middle of something else, that is, whenever one cannot tell what is being said of what. That is not a step backward; it is the cycle working as it should.
